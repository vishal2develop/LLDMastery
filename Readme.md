# Tic-Tac-Toe

## MVP 

Support:

```
Initialize game
Make move
Validate move
Update board
Check winner
Check draw
Switch player
```

Single Tic Tac Toe game:
```
2 players
3x3 board
make move
validate move
check win
check draw
switch player
```
