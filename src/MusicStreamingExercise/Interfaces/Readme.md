# Exercise: Iterator Pattern for Playlist Management
## Problem Statement
Imagine you are developing a Music Streaming App that allows users to manage playlists. Each Playlist contains a collection of Songs, and users should be able to browse through the songs in the playlist one at a time.

Your task is to use the Iterator Pattern to:
- Encapsulate the logic for traversing the songs in the playlist.
- Ensure that the client code (user interface) doesn’t need to know the internal structure of the playlist.
